# Sandbox

Local is a compatibility option for trusted diagnostics. It restricts paths, working directory, timeouts, environment variables, and output size, but it is not a strong security boundary. Use Shipyard Neo for untrusted repositories.

Shipyard requires a base URL, API key, and profile. A single shell request is capped at 300 seconds while the Controller keeps larger outer tool and task limits. The Setup Wizard creates a temporary workspace, verifies read/write/command behavior, and destroys it.

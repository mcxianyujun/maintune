# Maintune v0.1.0 Stable Preparation Goals

Status: In Progress

## 目标

从已发布的 v0.1.0-preview.3 开始，准备 v0.1.0 stable，并建立第一个官方插件生态。

## 核心原则

- 不继续扩大 Preview 3 的 Plugin API v2 范围
- 优先稳定 API、开发者体验和官方插件
- Core 与 Plugin 保持边界
- Agent 自主执行时遵循本文档

## Autonomous Execution Policy

- Agent 按 Phase 顺序执行
- 不需要每个 Phase 请求人工确认
- 只有遇到范围变化、重大架构选择、安全风险、发布决策才暂停
- 每完成一个 Phase 更新状态并生成报告

## Out of Scope

- Plugin Event Bus
- Custom Task Types
- ReviewProvider abstraction
- Tool streaming
- Plugin signing
- Plugin marketplace
- Remote plugin runtime
- Automatic plugin rollback
- Major Plugin API redesign

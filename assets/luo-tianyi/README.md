# Luo Tianyi third-party artwork slot

No official or externally sourced third-party Luo Tianyi artwork is distributed in `v0.1.0-preview.1` at this time.

The default interface uses the requested blue-white visual language built around `#66CCFF`. Its hero and navigation images are project-generated Luo Tianyi fan illustrations stored under `frontend/src/assets/theme/`. In the project author's owned or controlled rights, these visuals use CC BY-NC-SA 4.0. They are not official artwork; Luo Tianyi / VSINGER character and underlying IP rights remain with their rights holders and are excluded from both AGPL and CC licensing. See `docs/licensing/asset-attribution.md`.

Artwork may be added only after its original source, author or rights holder, modification permission, redistribution permission, commercial-use status and attribution terms have all been recorded in this directory.

Project source code is licensed under AGPL-3.0-only. Any future third-party artwork will retain its separate license and will not automatically be covered by AGPL-3.0-only.
